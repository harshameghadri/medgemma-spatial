From a Visium section to a checked draft report

MedGemma 4B, grounded in curated ligand–receptor facts, with automatic checks on every report

Knowledge base
Curated axis table

23 ligand–receptor axes: sender → receiver, effect on the receiving cell, agent class. Every pair confirmed in an OmniPath snapshot (15,208 pairs); signed off by a domain reviewer.

CD47–SIRPα: Epithelial → Macrophages; inhibits phagocytosis
1 · Input
10x Visium sample
  • Space Ranger output or .h5ad
  • Gene expression per spot
  • H&E image (optional)
2 · Spatial analysis
Scanpy + Squidpy
  • QC and cell-type annotation
  • Moran's I autocorrelation
  • Neighbourhood entropy
  • Cell-type co-enrichment
→ feature summary and tissue phenotype
3 · Evidence prompt
Features + matching axes
  • Up to 6 axes whose sender and receiver are both in the sample
  • Ranked by context (myeloid, stromal, desert, immune, TLS)
  • Therapy rules from the blinded read, e.g. checkpoint blockade does not recruit T cells into a desert
4 · Generation
MedGemma 4B
  • Text only, or text + H&E
  • 4-bit, local GPU
  • Four sections: microenvironment, mechanism, therapy, caveats
5 · Checks
Draft report + warnings
  • Numbers and cell types not in the input
  • Citations looked up in PubMed
  • Text copied from the prompt
  • Biology check: 6 error kinds, e.g. an inhibitory axis described as activating

Each prompt design was compared on 31 held-out prompts with criteria fixed before generation, then in a blinded biology read by a domain reviewer; results in the companion figure.
